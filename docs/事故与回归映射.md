# 事故 → 回归用例映射

> 每次修复用户可见事故，先登记编号，再在 `src/Tests.cs` 或 `src/UiTests.cs` 增加/补强对应断言；合入 `main` 前必须能在本表找到回归入口。

## 编号规则

- `DATA-*`：数据、迁移、备份与凭据卫生
- `TIMER-*`：番茄钟、挑战、暂停、休息与时间边界
- `TASK-*`：任务拆解、子任务、接续卡与完成状态
- `SYNC-*`：导入、导出、WebDAV、幂等与冲突
- `AI-*`：AI 请求、失败降级、隐私和编辑保护
- `UI-*`：界面布局、交互、DPI 和入口
- `OBS-*`：运行日志、统计与排障可见性

## 已登记事故与回归入口

| 编号 | 事故/风险 | 双侧防御 | 回归用例入口 |
|---|---|---|---|
| DATA-001 | 数据损坏后不能启动或覆盖原文件 | `.bak` 恢复并保留 `.damaged-*` | `Tests.cs`：`backup recovered`、`damaged preserved` |
| DATA-002 | API 密钥进入数据文件或备份 | Windows 加密保存；导出/备份排除凭据 | `Tests.cs`：`secret encrypted`、`no plaintext secret on disk` |
| TIMER-001 | 睡眠/长中断被误算为专注 | 超过 120 秒自动暂停并记录 interrupted | `Tests.cs`：`suspension detected`、`sleep not counted` |
| TIMER-002 | 挑战计时越过阶段或总时限 | 阶段边界、总时限和加时均截断记录 | `Tests.cs`：`first allocation boundary`、`challenge end shifts by used overtime` |
| TIMER-003 | 申请加时被错误限制为 1 分钟 | 单次上限按项目初始总时长，独立于当前阶段剩余 | `Tests.cs`：`screenshot scenario accepts 30-minute overtime`、`30-minute overtime remains 30 minutes` |
| TASK-001 | 完成/撤回子任务后下一步不前进 | 状态保存并刷新当前截止点 | `UiTests.cs`：`step completion advances current action`、`step undo restores action` |
| TASK-002 | 中断后无法接上原动作 | 保存停点、接续线索和下一步动作 | `UiTests.cs`：`pause remembers current action` |
| SYNC-001 | 重复同步产生重复计时记录 | RunId 去重、原子写、合并幂等 | `Tests.cs`：`merge deduplicates time`、`repeated import idempotent` |
| SYNC-002 | WebDAV 冲突覆盖其他设备数据 | ETag + `If-Match`，412 后重新下载 | `Tests.cs`：`cloud update guarded by ETag`、`conflict recovery no duplicate records` |
| AI-001 | AI 失败影响主流程或覆盖用户修改 | fail-open；异步结果按编辑版本保护 | `UiTests.cs`：`late AI result preserves user edits`、`AI failure preserves original task` |
| UI-001 | 高 DPI 下倒计时/阶段内容裁切 | 实际 DPI 测量并保留阶段行高度 | `UiTests.cs`：`countdown height must fit actual DPI font`、`five stage rows visible without scrolling` |
| OBS-001 | 运行事件只写不读，无法排障 | 本地日志对话框、筛选、CSV 导出、清空确认 | `Dialogs.cs`：`RuntimeLogDialog`；`Tests.cs`：`runtime log CSV`、`runtime log cap` |
